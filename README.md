# ⌚ Smart Watch Landing Page Website

## 📌 Project Overview
This is a simple Smart Watch landing page website built using HTML, CSS, and JavaScript.  
It displays a product layout with navigation, image gallery, and basic user interaction.

---

 🚀 Features
- Responsive navigation bar (Home, New, Profile, Shop, Contact)
- Watch product showcase section
- Watch image gallery (4 images)
- Dark/Light mode toggle
- Buy Now button with confirmation message
- Clean and simple UI design


🛠️ Technologies Used
- HTML (structure)
- CSS (styling and layout)
- JavaScript (basic interactivity)


 💡 What I Learned
- How to create a structured webpage using HTML
- How to style components using CSS Flexbox
- How to add basic interactivity using JavaScript
- How to connect multiple files in a project
